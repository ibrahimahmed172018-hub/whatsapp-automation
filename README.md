# 🛵 بوت دليفري طنطا (WhatsApp Delivery Bot)

بوت واتساب متقدم لإدارة وتوصيل الطلبات في طنطا مبني باستخدام Node.js و whatsapp-web.js و better-sqlite3 و Express.

## 🛠️ المميزات
- **6 أقسام للخدمات**: دليفري وطلبات خاصة، مطاعم طنطا، تسوق، صيدليات، محلات، خدمة العملاء.
- **مسح رمز QR مباشر**: صفحة ويب متجددة تلقائياً كل 5 ثوانٍ على `/qr` بالإضافة لطباعة الرمز في التيرمينال.
- **أوامر الإدارة داخل المحادثة**:
  - `/add_restaurant <الاسم>`: إضافة مطعم ورفع صورة المنيو.
  - `/restaurants`: عرض قائمة المطاعم المسجلة.
  - `/del_restaurant <ID>`: حذف مطعم.
  - `/orders`: عرض آخر 10 طلبات مع أرقام الهواتف والحالات.
  - `/status <order_id> <new_status>`: تحديث حالة الطلب وإرسال إشعار فوري للعميل.
  - `/stats`: إحصائيات تفصيلية عن العملاء والطلبات والمطاعم.
- **إشعارات فورية للإدارة**: تحويل الطلبات وتفاصيلها وصور الروشتات والمنيو فوراً لرقم الأدمن.
- **جاهز للرفع على Railway**: توقيت القاهرة `Africa/Cairo`، و Chromium جاهز مع كاش دائم في Dockerfile.

## 🚀 التشغيل
```bash
npm install
npm start
```
صفحة مسح الـ QR: `http://localhost:3000/qr`

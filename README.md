# 🛵 بوت دليفري طنطا (Telegram Delivery Bot)

بوت تيليجرام خفيف وسريع لإدارة وتوصيل الطلبات في طنطا مبني باستخدام Node.js و Telegraf و SQLite.

## 🛠️ المميزات
- **6 أقسام للخدمات**: دليفري وطلبات خاصة، مطاعم طنطا، تسوق، صيدليات، محلات، خدمة العملاء.
- **لوحة تحكم للمدير**: عرض آخر 10 طلبات، إحصائيات، وإشعارات فورية للإدارة عند تأكيد أي طلب.
- **قاعدة بيانات SQLite**: حفظ آمن وسريع للمستخدمين والطلبات بوضع WAL.
- **جاهز للرفع**: إعدادات متوافقة للعمل كـ Worker على Railway أو أي استضافة Node.js.

## 🚀 التشغيل
```bash
npm install
npm start
```
